# 🍔 Swiggy Competitor Price Intelligence Bot

यह एक **Ultra-Fast & Automated Competitor Price Intelligence Platform** hai jo Swiggy Native Location Engine aur Web Scraper ko use karke competitor prices compare karta hai.

---

## 📁 Clean Core Files (केवल ज़रूरी फ़ाइलें)

1. **[app.py](file:///f:/pricescheckbot/app.py)** — Main Streamlit Web Dashboard UI & Orchestrator.
2. **[search_helper.py](file:///f:/pricescheckbot/search_helper.py)** — Swiggy Native Area Collection & Link Finder Engine.
3. **[swiggy_scraper.py](file:///f:/pricescheckbot/swiggy_scraper.py)** — Swiggy Ultra-Fast Menu & Price Scraper Engine.
4. **[matcher.py](file:///f:/pricescheckbot/matcher.py)** — Fuzzy Food Item & Price Matching Engine.
5. **[requirements.txt](file:///f:/pricescheckbot/requirements.txt)** — Dependencies (`requests`, `curl_cffi`, `playwright`, `streamlit`, `pandas`).

---

## 🚀 How to Run (कैसे चलाएं)

```bash
streamlit run app.py
```
*(Browser me **http://localhost:8501** open ho jayega)*

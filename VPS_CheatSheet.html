ETHERS DASHBOARD — VPS CHEAT SHEET

Location: f:\ethersdashboard\VPS_CheatSheet.html

1. Monitoring & PM2 Commands

PM2 Status Check
Check if Next.js, Hygiene Check, and Picture Automation are running (online/green).
pm2 status
View Real-Time Logs
Check live errors, DDGS search queries, or API logs.
pm2 logs                      # All logs
pm2 logs ethers-next            # Next.js frontend logs
pm2 logs ethers-hygiene         # Python hygiene engine logs
pm2 logs ethers-picture         # Python picture automation logs
Restart Services
Restart all background services without downtime.
pm2 restart all

2. GitHub Deployment & Updates

Pull Latest Code & Rebuild
Run when new features or fixes are pushed to GitHub.
cd /var/www/ethersdashboard
git pull
npm run build
pm2 restart ethers-next

3. Environment Secrets (.env)

Edit GEMINI_API_KEY or Session Secret
Edit environment variables directly on VPS.
nano /var/www/ethersdashboard/.env

# Reload memory in PM2 after editing:
pm2 restart ethers-next --update-env

4. Nginx & Domain

Nginx Test & SSL Renewal
Verify Nginx config and SSL certificate status.
nginx -t && systemctl reload nginx
certbot renew
